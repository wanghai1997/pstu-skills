# 命令行待办事项列表 - 完整实现

## 项目描述
这是一个命令行待办事项列表应用，通过分阶段逐步实现，完整演示了Python编程的核心概念。

## 已实现的功能

### 核心功能
- ✅ **添加任务**：输入新任务并保存到列表
- ✅ **查看任务**：显示所有待办事项（带编号和完成状态）
- ✅ **标记完成**：将任务状态改为已完成（用[+]表示）
- ✅ **删除任务**：移除不需要的任务（带确认提示）
- ✅ **文件存储**：数据自动保存到 `todos.txt`，重启程序后数据不丢失

### 技术特性
- 完善的输入验证（检查空输入、无效编号等）
- 健壮的异常处理（文件操作、类型转换等）
- 用户友好的交互界面
- 退出确认（防止误操作）
- 兼容Windows命令行（处理编码问题）

## 使用方法

### 运行程序
```bash
python todo_app.py
```

### 操作指南
1. **启动程序**：自动加载已保存的任务（如果存在）
2. **添加任务**：选择选项1，输入任务内容
3. **查看任务**：选择选项2，查看所有任务列表
4. **标记完成**：选择选项3，输入任务编号
5. **删除任务**：选择选项4，输入任务编号并确认
6. **退出程序**：选择选项5，确认后退出
